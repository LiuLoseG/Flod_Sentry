## 1. 三代离散化的演变

模块里的一阶低通经历过三种写法，把三者放在同一张表里比较，才能说明为什么最终选双线性。

### 1.1 三代公式

```text
一代（模拟近似）:  x = 2π·fc·T
                   α = x/(1+x)
                   y[n] = y[n-1] + α·(x[n] − y[n-1])

二代（匹配Z / 冲激响应不变）:
                   α = 1 − e^(−2π·fc·T)             ← 上一版代码的写法: 名义上 -3dB 准确, 相位偏小
                   y[n] = y[n-1] + α·(x[n] − y[n-1])

三代（双线性 + 预畸变，当前实现）:
                   K  = tan(π·fc·T)
                   b0 = K/(1+K),  p = (1−K)/(1+K)
                   y[n] = y[n-1] + b0·((x[n] + x[n-1]) − 2·y[n-1])
```

### 1.2 实测对比（T = 1ms）

|       设定 fc | 一代 -3dB | 二代 -3dB | **三代 -3dB** | 0.4·fc 处相位：一代 / 二代 / 三代 / 理想 |
| ------------: | --------: | --------: | ------------------: | ----------------------------------------- |
|         20 Hz |     18.86 |     20.03 |     **19.97** | −21.6 / −20.4 / −21.8 / −21.8         |
|         50 Hz |     43.75 |     50.42 |     **49.94** | −21.3 / −18.4 / −21.7 / −21.8         |
|         65 Hz |     55.04 |     65.92 |     **64.92** | −21.1 / −17.4 / −21.7 / −21.8         |
|        100 Hz |     79.18 |    103.47 |     **99.90** | −20.7 / −15.4 / −21.2 / −21.8         |
| 20 Hz @ T=5ms |     15.84 |     20.69 |     **19.98** | −20.7 / −15.4 / −21.2 / −21.8         |
| 30 Hz @ T=5ms |     21.96 |     32.52 |     **29.98** | −20.0 / −12.7 / −20.5 / −21.8         |

**读表要点**

1. 一代的 -3dB 系统性偏低，且 fc/fs 越大偏得越多（65Hz@1kHz 只到 55Hz，65Hz@200Hz 只到 39.8Hz）。用它在现场调参，相当于滤波器实际比你设的更"肉"。
2. 二代的 -3dB 很准（它就是按 -3dB 反解的），**但相位系统性偏小**：0.4·fc 处少 1.4°(fc=20Hz)、3.4°(fc=50Hz)、6.4°(fc=100Hz)，相对误差 6%~27%，随 fc/fs 增大。这类误差最危险——调参时觉得裕度够，实际已经不够。
3. 三代同时把幅频和相频钉在理想值上，且与 fc/fs 无关。

### 1.3 换到双线性会不会推翻现场已调好的参数？

不会，这是本次改动能安全落地的关键。现场用的是一代，与三代相比：

| fc=50Hz, T=1ms |  f=0.1fc |  f=0.4fc |               f=fc |               f=5fc |
| -------------- | -------: | -------: | -----------------: | ------------------: |
| 一代 \|H\|     |   0.9935 |   0.9091 |             0.6589 |              0.1902 |
| 双线性 \|H\|   |   0.9951 |   0.9294 |             0.7071 |              0.1564 |
| 变化           | +0.01 dB | +0.19 dB | **+0.61 dB** | **−1.70 dB** |

（fc=20Hz 时同一张表的变化只有 +0.01 / +0.08 / +0.26 / +0.09 dB，因为一代的偏差本身随 fc/fs 缩小）

结论：

- **相位几乎不变**（0.4fc 处 −21.3° → −21.7°，差 0.4°），所以已调好的相位裕度不需要重调。
- **带内幅值回升**（截止点 +0.61 dB，0.4fc 处 +0.19 dB）：滤波器不再白白多衰减，跟随误差会略变小。
- **远端抑制增强**（5fc 处 −1.70 dB）：对量化/开关噪声更有利。

唯一需要在台架上复核的是：原先某个环若依赖"实际截止频率只有 44Hz"带来的额外平滑，现在它真的到了 50Hz，会显得略"快"。建议改动后先跑一次阶跃/正弦跟踪，确认没有新的抖动。

## 2. 理论依据

### 2.1 双线性变换与预畸变

双线性变换用 `s = K·(z−1)/(z+1)` 把 s 平面映射到 z 平面，`K = 2·fs` 为默认频率缩放。它把 `s=0`（直流）映射到 `z=1`，`s=∞` 映射到 `z=−1`（Nyquist），左半平面映射到单位圆内，因此**稳定性必然保持**；代价是频率轴被非线性压缩（频率弯折），只有一点能精确对齐 [1]。

`K` 剩下的那一个自由度就是用来"钉住"某个频率的：想让模拟截止 `Ω_c` 精确落在数字截止 `w_c = 2π·fc·T`，需要

```text
Ω_c = K · tan(w_c/2) = 2·fs · tan(π·fc·T)
```

代码里把 `K` 归一化掉，只留下 `K' = Ω_c / K = tan(π·fc·T)`，这就是 `recalculate_coefficients()` 里那一行 `tanf(PI * fc * T)` 的来历。MATLAB `bilinear` 的预畸变写法 `fs = fp/tan(fp/fs/2)` 与此等价 [2]。

由此得到一阶低通 [3]：

```text
H(z) = b0(1 + z⁻¹)/(1 − p·z⁻¹)
b0 = K'/(1+K'),  p = (1−K')/(1+K')
```

- 直流增益：`2b0/(1−p) = 1`（精确）
- Nyquist 增益：`0`（零点在 `z=−1`）
- `|H(fc)| = 1/√2`（预畸变保证，实测 0.707107）
- 带内相位：`−atan(tan(πfT)/tan(πfcT))`，fc·T 小时即 `−atan(f/fc)`

### 2.2 为什么不用匹配Z / 冲激响应不变

匹配Z法把极点和零点按 `z = e^{sT}` 逐个映射 [4][5]，对一阶低通得到 `p = e^{−2π·fc·T}`、`b0 = 1−p`。它的问题是：

1. **相位偏小**。极点比双线性更靠近原点，群延迟小于模拟原型，通带相位少 ~15%。用它的相位预算会算乐观。
2. **Nyquist 有透传下限**。分子没有 Nyquist 零点，高频增益收敛到 `(1−p)/(1+p)`，fc/fs 越大这个下限越高。实测量化/开关噪声抑制对比如下（fc=50Hz，T=1ms）：

|   频率 | 双线性 \|H\| | 匹配Z \|H\| |                差值 |
| -----: | -----------: | ----------: | ------------------: |
| 250 Hz |       0.1564 |      0.2177 | **−2.87 dB** |
| 375 Hz |       0.0655 |      0.1683 | **−8.20 dB** |

3. **白噪声增益更高**（同一 -3dB 下）：

|     fc | 双线性噪声增益 | 匹配Z 噪声增益 |      差 |
| -----: | -------------: | -------------: | ------: |
|  10 Hz |         0.1746 |         0.1773 | 0.13 dB |
|  50 Hz |         0.3698 |         0.3980 | 0.64 dB |
| 100 Hz |         0.4952 |         0.5700 | 1.22 dB |
| 200 Hz |         0.6487 |         0.8524 | 2.37 dB |

双线性的白噪声增益有闭式：`sqrt(b0)`；等价地 `sqrt(α/2)`，其中 `α = 1−p` 为等效平滑系数。

### 2.3 二阶巴特沃斯

巴特沃斯滤波器是"最大平坦幅频"，`|H(jω)|² = 1/(1+(ω/ω_c)^{2N})`，在 ω_c 处恰好 −3dB，无通带纹波，极点均布于左半平面单位圆上 [6]。二阶（N=2）时 `Q = 1/√2`，s 域原型为

```text
H(s) = ω_c² / (s² + (ω_c/Q)·s + ω_c²)
```

经双线性（`K' = tan(π·fc·T)`，`norm = 1/(1 + K'/Q + K'²)`）：

```text
b = K'²·norm·[1, 2, 1]
a = [1, 2(K'²−1)·norm, (1 − K'/Q + K'²)·norm]
```

实现用**直接II型转置（TDF-II）**：每拍 5 乘 4 加、2 个状态，数值条件优于直接I型（状态变量不必与输入同量级）。

`Q` 可配：`Q < 0.7071` 更阻尼（无过冲），`Q = 0.7071` 巴特沃斯（阶跃过冲 4.3%）。
注意"两个相同一阶串联"并不等于巴特沃斯：它是 `Q = 0.5` 的过阻尼二阶，要把 -3dB 摆回 fc 需 `fc' = 1.5538·fc`（`= 1/sqrt(√2−1)`，已验证）。

#### Q 的语义（重要，容易踩）

`cutoff_frequency` 是**分母的自然频率 ω_n**，只有 `Q = 0.7071` 时它才等于 -3dB 点。解 `|H|² = 1/2` 得 `r = f3dB/fc` 满足

```text
r⁴ + (1/Q² − 2)·r² − 1 = 0
```

实测（标称 fc = 50 Hz，T = 1 ms）：

|      Q | ζ = 1/(2Q) |        f3dB / fc | \|H(fc)\| |        阶跃过冲 |   幅频峰 |
| -----: | ----------: | ---------------: | --------: | --------------: | -------: |
|   0.50 |       1.000 | **0.6436** | −6.02 dB | **0.00%** |     0 dB |
|   0.60 |       0.833 |           0.8271 | −4.44 dB |           0.93% |     0 dB |
| 0.7071 |       0.707 |           1.0000 | −3.01 dB |           4.44% |     0 dB |
|   1.00 |       0.500 |           1.2720 |   0.00 dB |          16.59% | +1.25 dB |
|   2.00 |       0.250 |           1.4845 |  +6.02 dB |          44.42% | +6.30 dB |

三个结论：

1. **"无过冲"的分界是 Q ≤ 0.5**（临界阻尼），不是 Q < 0.7071。Q=0.6 已经有 0.93% 过冲。
2. **降 Q 消过冲的代价是带宽收窄**：Q=0.5 时实际 -3dB 只有标称的 64%，等于把滤波器悄悄调慢了一倍多。要同时"无过冲 + 带宽正确"，应该用 Q=0.5 但把标称 fc 除以 0.6436（即 ×1.554），或者干脆用两级一阶串联。
3. **"幅频无峰"的分界才是 Q ≤ 0.7071**（此时峰值 0 dB；Q=1 已有 +1.25 dB 鼓包）。

代码提供 `get_minus3db_frequency()`（init 时算一次，不占运行时间）和 `set_q()`（运行时改 Q 且输出连续），可以用来核对或在线调整。

> 上表的 `f3dB/fc` 是**模拟原型**的比值。数字滤波器经双线性预畸变弯折后真实落点会略有差异
> （fc/fs=0.05 时 Q=2 为 **1.470** 而不是 1.485，Q=0.5 为 **0.647** 而不是 0.644）。
> `get_minus3db_frequency()` 已按 `f3dB = atan(r·tan(π·fc·T))/(π·T)` 做弯折，返回的就是真实数字频率；
> 早期版本只做 `r·fc`，在 fc/fs 较大时最多偏 1%。

#### biquad 的数值下限

直流增益 = `(b0+b1+b2)/(1+a1+a2)`，而这两个和都等于 `4K²/D`（约 `4K²`）。K 很小时它们都是 O(1) 项相消出来的小数，float 会丢掉有效位。从系数解析计算（不跑仿真）：

| fc/fs | fc @1kHz |                                    biquad 直流增益误差 | 一阶低通误差 |
| ----: | -------: | -----------------------------------------------------: | -----------: |
|  1e-1 |   100 Hz |                                               −0.000% |     −0.000% |
|  1e-2 |    10 Hz |                                               −0.001% |      +0.000% |
|  5e-3 |     5 Hz |                                                +0.014% |     −0.000% |
|  1e-3 |     1 Hz |                                     **−0.392%** |     −0.000% |
|  5e-4 |   0.5 Hz |                                                +0.132% |     −0.001% |
|  2e-4 |   0.2 Hz |                                               −1.963% |     −0.002% |
|  1e-4 |   0.1 Hz |                                    **−17.245%** |      +0.001% |
|  5e-5 |  0.05 Hz | **−265.548%**（分母算成 −5.96e-8，符号都反了） |     −0.002% |

注意误差是**非单调的抖动**（1e-3 时 −0.39%，5e-4 时反而只有 +0.13%）——这正是灾难性相消的特征，不能靠"再看看"来判断是否可用。

极点半径始终 < 1（**不会发散**，只会增益错），所以这个失效模式很隐蔽：滤波器很稳定，但增益偏了。

**规避**：fc/fs < 1e-3 时改用一阶 `low_pass_filter_class`（直流增益结构精确，1e-5 时误差仍 <0.02%）。或者 init 之后用 `get_dc_gain()` 自检：

```cpp
gimbal.some_filter.init(0.5f, 0.001f);        // fc/fs = 5e-4, 已在危险区
if (fabsf(gimbal.some_filter.get_dc_gain() - 1.0f) > 0.01f) { /* 换一阶或调高 fc */ }
```

### 2.4 中值滤波

中值滤波是顺序统计量滤波器：取窗口内排序后的中位数，对孤立冲激噪声（椒盐噪声）免疫，同时保留阶跃边缘 [7]。代价是非线性——它没有频响、没有相位概念，只能谈"窗口长度 ≈ 多少延迟"。窗口长度 N 时，阶跃延迟约 `(N−1)/2` 拍。

本实现用固定最大缓冲 + 运行时窗口长度（C++ 不允许 VLA 作成员），并且只做**部分选择排序**：中值只需中间 1~2 个元素，选择排序第 i 轮后 `[0,i]` 已定序，排到 `mid` 即可，数据移动从 `O(N²)` 降到 `O(N)`。

### 2.5 滑动均值的累加漂移

增量式滑动均值 `sum += new; sum −= oldest;` 是 O(1) 的，但**浮点下 `a−b+b ≠ a`**：每次加减都会留下舍入残差，残差留在累加器里做随机游走，永不衰减。这是朴素求和误差随项数线性增长（`O(n·ε)`）的直接后果；补偿求和（Kahan）通过额外保存误差项把误差压到 `O(ε)` 与 n 无关 [8]。

实测（float，窗口 8，输入 ±100，1kHz）：

| 运行时长         | 相对理想均值的漂移           |
| ---------------- | ---------------------------- |
| 1e4 拍（10 s）   | 2.3e-4                       |
| 1e6 拍（17 min） | 7.6e-4                       |
| 2e7 拍（5.5 h）  | **7e-3**（且仍在增长） |

对控制量而言 7e-3 还算小，但它是**无界增长**的，连续跑一整天就会到 1e-2 量级。本实现采用更省算力的替代方案：**每 64 拍从环形缓冲整窗重算一次** `sum`，把漂移钳在常数级（实测 2e6 拍内 ≤ 3.1e-5），平均代价 `N/64` 次加法/拍（N≤16 时约 0.25 次/拍）。

## 3. 各类实现说明

### 3.1 一阶低通 `low_pass_filter_class`

```cpp
now_output = last_output + b0 * ((now_input + last_input) - 2.0f * last_output);
last_input = now_input;
last_output = now_output;
```

**为什么写成增量形式**：`y = b0(x+x₁) + p·y₁` 与上式代数等价，但 float 下 `2b0 + p` 不一定严格等于 1，输入恒定时输出会缓慢漂移（实测 `reset()` 后 2000 拍漂 2e-6）。增量形式在输入恒定时括号内严格为 0，**直流不动点是精确的**。这一点很实用：`fc/fs = 1e-5` 时直流增益误差仍 <0.02%，而直接型 biquad 在同条件下已经算不出增益（见 §2.3）。

| 方法                           | 说明                                                                                      |
| ------------------------------ | ----------------------------------------------------------------------------------------- |
| `init(fc, T)`                | 清状态初始化。`T≤0` 回落到 1ms                                                         |
| `set_cutoff_frequency(fc)`   | 在线改截止频率，**保留状态，无输出跳变**（状态在 y 域，稳态换系数时括号内严格为 0） |
| `set_sampling_period(T)`     | 按实测任务周期修正，同样无跳变                                                            |
| `reset(v)`                   | 用 v 播种两路状态（`last_input` 也必须播种，否则首拍有半个阶跃）                        |
| `get_alpha()`                | 返回 `2·b0 = 1−p`，量纲与旧式 α 兼容，供遥测                                         |
| `get_coefficients(float[5])` | 按 CMSIS 顺序导出 `{b0,b1,b2,a1,a2}`                                                    |

参数钳位：`fc ≤ 0` → `b0 = 0`（输出冻结，不是直通）；`fc > 0.98·Nyquist` → 钳到 `0.98·Nyquist`；`fc < 1e-6/(πT)` → 抬高到该下限（防止极点吸附到 1 退化成纯积分器）。

### 3.2 二阶低通 `biquad_low_pass_filter_class`

TDF-II 递推：

```cpp
y       = b0*x + s1;
s1      = b1*x - a1*y + s2;
s2      = b2*x - a2*y;
now_output = y;
```

`reset(v)` 的稳态解：`s1 = (1−b0)v`，`s2 = (b2−a2)v`（不是 0！否则上电有冲击）。

**为什么改系数要重播状态**：TDF-II 的 `state_1/state_2` 是内部 v 域量，与分子系数绑定。换 Q 或换 fc 后若沿用旧状态，第一拍输出会跳变（实测换 Q 时约 0.14% 的信号量级）。因此 `set_cutoff_frequency()` / `set_q()` / `set_sampling_period()` 都会调用 `reseed_state()` 按当前输出重播状态，保证"输入此刻等于当前输出时，下一拍输出严格不变"。代价是丢掉状态里隐含的斜率（中途改参时轨迹有折角），但输出本身连续。

- 与一阶低通不同：一阶的状态就在 y 域（`last_output` + `last_input`），稳态换系数时括号内严格为 0，天然无跳变，不需要重播。

#### 数值边界

从系数解析计算 `(b0+b1+b2)/(1+a1+a2)`（T=1ms，见 §2.3 的完整表）：

| fc/fs |          biquad 直流增益误差 | 一阶低通误差 |
| ----: | ---------------------------: | -----------: |
|  1e-2 |                     −0.001% |      +0.000% |
|  1e-3 |           **−0.392%** |     −0.000% |
|  2e-4 |                     −1.963% |     −0.002% |
|  1e-4 |          **−17.245%** |      +0.001% |
|  5e-5 | −265.548%（分母符号都反了） |     −0.002% |

结论：**fc/fs < 1e-3 时不要用 biquad**，改用一阶（或按 §2.3 用 Q=0.5 预补偿两级串联）。原因是直接型系数在极点半径趋近 1 时发生相消丢精度。极点半径始终 < 1（不会发散），所以这是个**静默的增益错误**，靠观察输出稳定性发现不了——用 `get_dc_gain()` 自检。

实际控制中 1kHz 下 fc 低于 1Hz 已经很罕见，但仍应知道这条线。

### 3.3 一阶高通 `high_pass_filter_class`

```text
b0 = 1/(1+K'),  p = (1−K')/(1+K')
y[n] = b0·(x[n] − x[n-1]) + p·y[n-1]
```

零点在 `z=1`，因此 **直流增益严格为 0**（输入恒定时差分严格为 0，输出精确收敛到 0，无直流泄漏）。Nyquist 增益精确为 1。

对比旧实现（`α = e^(−2π·fc·T)`，匹配Z）：Nyquist 增益只有 `2α/(1+α)`，fc=50Hz@1kHz 时仅 **0.844（−1.5dB）**，高频有下垂。`reset(v)` 只需播种 `last_input`，输出置 0。

### 3.4 中值 `median_filter_class`

- 窗口 `1..16`（`Median_Filter_Max_Size`），运行时配置，`0` 钳到 1，超出钳到 16。
- **未满窗**时按已有数据取中值（奇数窗；偶数窗取中间两值平均），避免把未初始化的缓冲当有效值参与排序。
- 维护一份**始终升序**的副本 `sort_buffer`：每拍"删掉被覆盖的最旧值 + 插入新值"，各是一次 O(N) 移位，取中值按下标 O(1)。
  不再每拍复制整窗再做部分选择排序（那是 O(N²)）。重复值无需区分身份——删掉任意一个等值元素即可。
  主机侧同进程 A/B 实测（g++ -O2，PC，各取 3 次最好值）：N=16 由 **107.5 ns/call 降到 28.1 ns/call（3.8×）**，
  N=8 由 29.7 降到 20.3 ns（1.5×），N=3 由 9.2 降到 8.4 ns（1.1×）；
  正确性由"随机数据 + 大量重复值 + 任意窗口长度的暴力排序对照"性质测试保证。
- `reset(v)` 把整窗填成 v（`data_count = 窗口长度`），用于上电/切模式。`init()` 只清计数不清数据，切模式后前 N 拍里旧数据仍在环形缓冲里参与中值，表现为最多 N 拍的输出跳变。

### 3.5 滑动均值 `sliding_mean_filter_class`

- 窗口 `1..16`，`O(1)` 增量累加 + 每 64 拍整窗重算（见 §2.5）。
- 未满窗按已有数据取均值。
- `reset(v)` 填满整窗并同步 `sum`，切换时输出立即为 v，无需等待 N 拍。

### 3.6 自适应 `adaptive_filter_class`

按绝对值误差在三段之间调度 α（`err_low < err < err_high` 线性插值），`err ≤ err_low` 用 α_min，`err ≥ err_high` 用 α_max。递推仍是 `y += α(x−y)` 的半离散形式——因为 α 本身在线插值，它**不是**一个固定截止频率的线性系统，所以没有可预测的相位。

> 需要可预测相位预算的通道，请用 `low_pass_filter_class` / `biquad_low_pass_filter_class`。

参数防呆分两层：

- `init()` 先把 `α_min/α_max` 钳到 `[0,1]`（超出会得到负阻尼或越界插值），再处理 `α_min ≥ α_max` / `err_low ≥ err_high`（自动拉开 1e-6，避免除零）。
- `adaptive_calculate_callback()` 里对插值结果再钳一次 `[0,1]`。只在 init 做不够——调用方可能在运行中传非法参数，一次 `α>1` 就会让输出冲过输入并反向振荡。

`reset(v)` 会同时清 `abs_err` 与 α。

### 3.7 共同的非有限输入保护

所有 `*_calculate_callback()` 入口都有

```cpp
if (!(now_input > -1.0e18f && now_input < 1.0e18f)) { /* 保持上一拍输出/整拍跳过 */ return; }
```

原因不是洁癖：一次 NaN 会永久污染状态——滑动均值的 `sum` 变 NaN 后永不复原；中值滤波的 NaN 比较全为 false 会卡在排序缓冲里；自适应滤波的 `abs_err` 变 NaN 后 α 永久为 NaN，而且这些污染会顺着控制链扩散到力矩输出。

## 4. 使用约束与调参指南

### 4.1 fc ≤ fs/4

一阶双线性的极点 `p = (1−K)/(1+K)` 在 `K > 1`（即 `fc > fs/4`）时变负，阶跃开始过冲：

| fc/fs | 阶跃过冲 |
| ----: | -------: |
|  0.05 |    0.00% |
|  0.10 |    0.00% |
|  0.20 |    0.00% |
|  0.25 |    0.00% |
|  0.30 |   +6.66% |
|  0.40 |  +12.50% |

超过 0.25 后它已经不是"一阶"了，别再按一阶的直觉调参。

### 4.2 阶跃 t63 与 1/(2π·fc) 的关系

双线性有 Nyquist 零点，阶跃起始段比模拟原型"慢半拍"，t63 比 `1/(2π·fc)` 晚：

|              fc/fs |     t63 | 相对 `1/(2π·fc)` |
| -----------------: | ------: | -------------------: |
|  0.01（10Hz@1kHz） | 16.4 ms |                +3.1% |
|  0.05（50Hz@1kHz） | 3.70 ms |               +16.3% |
| 0.10（100Hz@1kHz） | 2.09 ms |               +31.2% |

t63 的精确闭式（`n` 为 0 基采样下标）：

```text
y[n] = 1 − (1−b0)·p^n
t63  = T·( ln(0.368/(1−b0)) / ln(p) + 1 )
```

极点本身的时间常数 `τ = −T/ln(p)` 与模拟值 `1/(2π·fc)` 相差 <10%（fc/fs ≤ 0.1），所以"响应快慢"没有实质变化，只是起始段慢了半拍。

### 4.3 相位预算表（T = 1ms，单位：度，负为滞后）

用 `−atan(tan(πfT)/tan(πfcT))` 计算；fc/fs ≤ 0.1 时与教科书式 `−atan(f/fc)` 相差 <1°。

| fc (Hz) |    1 Hz |    2 Hz |    5 Hz |   10 Hz |   20 Hz |   40 Hz |
| ------: | ------: | ------: | ------: | ------: | ------: | ------: |
|       5 | −11.31 | −21.80 |      — |      — |      — |      — |
|      10 |  −5.71 | −11.31 | −26.56 |      — |      — |      — |
|      15 |  −3.81 |  −7.59 | −18.42 | −33.68 |      — |      — |
|      45 |  −1.26 |  −2.53 |  −6.30 | −12.45 | −23.85 | −41.59 |
|      50 |  −1.14 |  −2.27 |  −5.66 | −11.22 | −21.66 | −38.58 |
|      65 |  −0.87 |  −1.74 |  −4.34 |  −8.63 | −16.90 | −31.38 |
|     100 |  −0.55 |  −1.11 |  −2.77 |  −5.52 | −10.96 | −21.25 |

### 4.4 一阶还是二阶

同为 -3dB = 50Hz（T=1ms，实测）：

|   频率 | 一阶 \|H\| | 二阶 \|H\| |               幅值差 |  一阶相位 |   二阶相位 |  相位代价 |
| -----: | ---------: | ---------: | -------------------: | --------: | ---------: | --------: |
|   2 Hz |     0.9992 |     1.0000 |             +0.01 dB |  −2.27° |   −3.22° |  −0.95° |
|   5 Hz |     0.9951 |     1.0000 |             +0.04 dB |  −5.66° |   −8.06° |  −2.40° |
|  10 Hz |     0.9809 |     0.9992 |             +0.16 dB | −11.22° |  −16.28° |  −5.06° |
|  20 Hz |     0.9294 |     0.9878 |             +0.53 dB | −21.66° |  −33.70° | −12.04° |
|  40 Hz |     0.7818 |     0.8437 |             +0.66 dB | −38.58° |  −72.12° | −33.54° |
|  50 Hz |     0.7071 |     0.7071 |              0.00 dB | −45.00° |  −90.00° | −45.00° |
| 100 Hz |     0.4382 |     0.2312 |  **−5.55 dB** | −64.01° | −137.88° | −73.87° |
| 200 Hz |     0.2130 |     0.0475 | **−13.03 dB** | −77.70° | −162.06° | −84.36° |

（本表可用 §5.2 的 `response()` 直接复算，逐格与实现一致）

**选择依据**：判断标准不是"二阶比一阶好"，而是看**幅频收益值不值那些相位**。

以 fc = 50Hz 为例（同为 -3dB = 50Hz）：

- **通带内**（≤0.4·fc）二阶更平：20Hz 处一阶已衰减 0.64dB，二阶只衰减 0.11dB（差 0.53dB）。
- **阻带内**二阶更陡：100Hz 处多压 5.55dB，200Hz 处多压 13.0dB。
- **代价是相位**：20Hz 处多 12.04°。

所以：噪声集中在环路带宽附近（几倍 fc 以内）→ 一阶更划算，二阶多压的那点量不值得多付 12°；
要压的是远高于 fc 的噪声（编码器量化、开关噪声、PWM 纹波）→ 才值得付二阶的相位。

### 4.5 想用二阶但不想过冲：三种做法

巴特沃斯（Q=0.7071）虽然有 4.3% 的阶跃过冲，在位置环里通常可以接受（力矩环的带宽远高于此，过冲不会直接变成机械抖动）。若确实不能接受，按代价从小到大：

1. **接受 4.3% 过冲，用巴特沃斯**。幅频无峰、-3dB 精确、系数最简单。绝大多数情况选这个。
2. **Q=0.5 + 标称 fc × 1.554**。这样 -3dB 才落回你想要的频率：

   ```cpp
   // 想要 -3dB = 50Hz 且零过冲: 标称 50*1.554 = 77.7Hz
   f.init(77.7f, 0.001f, 0.5f);
   // 核对: get_minus3db_frequency() 应≈50
   ```
3. **两级一阶串联**（各 `fc' = 1.554·fc`）。每个环节都能用 `reset()` 独立播种，滤波器对象多一个、多一次函数调用，但全都是结构精确的一阶，最坏情况可预测。

不要做的事：**直接用 Q=0.5 而不补偿标称 fc**。这样得到的滤波器带宽只有标称的 64%，你会以为在做 50Hz 实际在做 32Hz——跟随误差变大，然后去怪 PID。

### 4.6 上电与切模式

`init()` 会清零状态。运行中重新初始化会让输出从 0 爬升，造成力矩冲击。正确做法：

```cpp
// 上电 / 切模式：用当前测量值播种
gimbal.big_pitch_omega.reset(imu_pitch_gyro);

// 在线改参：不要重新 init()
gimbal.big_pitch_omega.set_cutoff_frequency(80.0f);
```

### 4.7 采样周期必须填对

`init(fc, T)` 的 `T` 必须等于 `*_calculate_callback()` 的真实调用间隔。填错时 -3dB 会**成比例**偏：实际截止频率 = `fc × (填的 T / 真实 T)`（T 填大一倍 → 实际截止高一倍），而且**不会报错**。若任务周期随调度变化，用 `set_sampling_period()` 按 DWT 实测值修正。

`-3dB 与 T 无关`（同一个 fc，T 从 0.5ms 到 5ms 实测 |H(fc)| 均为 0.707107），但白噪声增益随 T 增大而升高（同一 fc 下带宽占比更大）：

|      T |       b0 |   极点 | 白噪声增益 |
| -----: | -------: | -----: | ---------: |
| 0.5 ms | 0.030469 | 0.9391 |     0.1746 |
|   1 ms | 0.059191 | 0.8816 |     0.2433 |
|   2 ms | 0.112160 | 0.7757 |     0.3349 |
|   5 ms | 0.245237 | 0.5095 |     0.4952 |

（fc = 20Hz）

### 5.2 如何独立复核（不依赖仓库内脚本）

设计结论都能用下面三段自包含代码复算。任一条与本表不符，说明实现与设计脱节。

**① 系数闭式解**（对照 `get_coefficients()`）：

```python
import numpy as np, math

def lp_coeff(fc, T):
    """一阶低通: 返回 (b0, b1, b2, a1, a2)，CMSIS 符号约定"""
    K = math.tan(math.pi * fc * T)
    b0 = K / (1.0 + K)
    return b0, b0, 0.0, 1.0 - 2.0 * b0, 0.0

def bq_coeff(fc, T, Q=0.7071067811865476):
    """二阶巴特沃斯(任意 Q): 同上约定"""
    K = math.tan(math.pi * fc * T)
    norm = 1.0 / (1.0 + K / Q + K * K)
    b0 = K * K * norm
    return b0, 2.0 * b0, b0, -2.0 * (K * K - 1.0) * norm, -(1.0 - K / Q + K * K) * norm
```

**② 用 scipy 复算频响**（对照 §4.3/§4.4 的表）：

```python
from scipy import signal

def response(coeff, T, freqs):
    """coeff 为 (b0,b1,b2,a1,a2); 返回 (|H|, 相位 deg) 数组"""
    b = np.array(coeff[:3])
    a = np.array([1.0, -coeff[3], -coeff[4]])   # CMSIS 的 a 已取反, 这里还原标准分母
    _, h = signal.freqz(b, a, worN=2 * np.pi * np.asarray(freqs, dtype=float) * T)
    return np.abs(h), np.angle(h, deg=True)

# 一阶 vs 二阶, fc=50Hz, T=1ms, 查 20Hz 与 100Hz
m1, p1 = response(lp_coeff(50, 1e-3), 1e-3, [20, 100])
m2, p2 = response(bq_coeff(50, 1e-3), 1e-3, [20, 100])
# 应得  m1 = [0.9294, 0.4382]  p1 = [-21.66, -64.01]
#       m2 = [0.9878, 0.2312]  p2 = [-33.70, -137.88]
```

若要验证"scipy 自己设计的滤波器与我们的实现一致"，把模拟原型**预畸变**后再交给 `scipy.signal.bilinear`：

```python
def reference_lowpass(fc, T):
    fs = 1.0 / T
    K = 2.0 * fs
    omega_c = K * math.tan(math.pi * fc * T)   # 预畸变: 让 -3dB 精确落在 fc
    return signal.bilinear(np.array([omega_c]), np.array([1.0, omega_c]), fs)
```

漏掉预畸变是这块最常见的错误：直接拿 `omega_c = 2π·fc` 送进 `bilinear`，
`fc=5Hz@1kHz` 得到的 b0 会从第 4 位有效数字起就不同。

**③ 最小自检**（编译进固件或主机程序都行）：`init()` 之后检查直流增益应 ≈1，
`get_dc_gain()` 偏离 1 说明该 fc/fs 已超出直接型 biquad 的精度范围（见 §2.3）。

### 5.4 测试方法学的坑（改测试前必读）

这几条都是本次实测踩出来的，写在这里避免重复踩：

1. **频响必须用整数个周期的窗口做正交解调**。`1/(f·T)` 不是整数时窗口不闭合，泄漏让 -3dB 判定漂移；同时 `f` 不能贴近 Nyquist（单周期 2 点采样时解调无意义）。
2. **t63 必须在采样点之间插值**。T=1ms 时理论 t63 = 3.18ms，直接取采样点会量成 4ms（26% 误差），然后把一个正确的实现判成失败。
3. **伪随机数要按位宽正确归一化**。`(lcg>>8)` 是 24 位，除以 `2^23` 得到的是 `[0,2)` 而不是 `[-1,1)`；据此写"输出应被输入幅度约束"的断言会必然失败（曾在量程检查里得到 18.0 > 10.0 的假失败）。
4. **单调性检查的 `prev` 必须用首个测量值初始化**。从 0 开始比较时第一次必然"上升"，从而把无峰的滤波器判成有峰。
5. **别用某个离散化的响应去反解模拟域结论**。例如"两节串联需 fc'=1.554fc"是模拟域结论，用匹配Z的离散响应反解会得到 1.53，而不是实现错了。

### 5.5 全带不变量与离线验证结论

§5.1~§5.3 的正弦测量只看几个频点。下面这几条覆盖 0..Nyquist 整条曲线，曾用主机侧离线仿真逐条核对
（仿真覆盖的是同一份 `general_filter.cpp`，结论与实现等价）：

| 不变量                             | 实测                                              | 意义                                    |
| ---------------------------------- | ------------------------------------------------- | --------------------------------------- |
| 白噪声增益 = `sqrt(mean(\|H\|²))` | 一阶 √b0、biquad（Q=0.7071/0.5）、高通全部 2% 内 | 系数/状态顺序写错会立刻偏离             |
| 幅频单调、无峰                     | 0.05·fc 到 Nyquist 逐点递减（5 个 Q）            | 抓"用模拟系数当数字系数"这类错          |
| 远端滚降 -20 / -40 dB/dec          | 一阶 -20.6、biquad -39.4（[2fc,10fc]）            | 确认阶数正确（Q 只改带宽不改阶数）      |
| 截止频率翻倍 → t63 缩小           | 0.563 倍（不是 0.5）                              | 数字域多了`+1 拍`固定延迟项，见 §4.2 |
| float 递推 vs double 参照          | fc/fs ≥ 0.005 时相对误差 < 0.1%                  | 定量支撑"fc/fs 太小要改结构"的限制      |

一阶低通的噪声增益恰好是 `√b0`（因为双线性结构 `b0(1+z⁻¹)/(1−(1−2b0)z⁻¹)` 的积分能约掉），
不是单极点形式 `sqrt(α/(2−α))`。

**这轮核对中修掉的真实问题**：

1. `get_minus3db_frequency()` 未做双线性弯折（见 §2.3 的注），fc/fs 较大时偏 1%。
2. 中值滤波器原实现是 O(N²)（每拍复制整窗 + 部分选择排序），N=16 时 107.5 ns/call（PC, g++ -O2）；
   改为维护升序副本后 28.1 ns/call（3.8×），N=8 29.7→20.3 ns。正确性由"随机数据 + 大量重复值 +
   任意窗口长度与暴力排序逐拍对照"保证。
3. `high_pass_filter_class` 缺少 `set_sampling_period()`（一阶低通和 biquad 都有），已补，
   并确认恒值输入下改参不产生输出跳变。

**行为边界**（核对时确认，不是 bug）：

- 数字域 t63 与模拟 `1/(2πfc)` 差一个 `+T` 的固定延迟项，fc/fs 越大比例越显著（§4.2 闭式已含此项）。
- `init()` 只清计数不清数据，中值/滑动均值切模式后前 N 拍旧数据仍参与运算，需要 `reset(v)` 才能立即生效。

## 7. 与其他实现的互操作

### 7.1 迁移到 CMSIS-DSP

`get_coefficients()` 按 CMSIS `arm_biquad_cascade_df1` 的系数顺序导出 `{b0, b1, b2, a1, a2}`，**并且已把分母系数取反**，因为 CMSIS 的递推是

```text
y[n] = b0·x[n] + b1·x[n−1] + b2·x[n−2] + a1·y[n−1] + a2·y[n−2]
```

而标准形式是 `... − a1·y[n−1] − a2·y[n−2]`，所以 `a` 必须取负 [9]。这一步极易写错，已在 `[17]` 段逐拍对照验证。

```cpp
float c[5];
f.get_coefficients(c);                       // 一阶: {b0,b0,0,p,0}；二阶: {b0,b1,b2,-a1,-a2}
arm_biquad_casd_df1_inst_f32 inst;
float32_t state[4] = {0};
arm_biquad_cascade_df1_init_f32(&inst, 1, c, state);
arm_biquad_cascade_df1_f32(&inst, in, out, blockSize);
```

实测（200k 采样随机输入）：一阶差 ≤1e-6、二阶差 ≤8e-6（直接型 I vs TDF-II 的舍入差异），块处理与逐拍处理一致。

> 两点差异要注意：
>
> 1. `reset(v)` 没有 CMSIS 侧的等价操作。若用 CMSIS 实现，上电播种需自己把 `state[4]` 设为 `{v, v, v, v}`。
> 2. CMSIS 没有"改系数重播状态"的概念。若在 CMSIS 侧做在线改参，需自己把 `state[]` 置成新系数下的稳态值，否则会跳变（见 §3.2）。

### 7.2 与 MATLAB / Python 对齐

预畸变形式：MATLAB `bilinear(b, a, fs, fp)` 的 `fp` 传 `fc` 即可；Python `scipy.signal.bilinear(b_analog_prewarped, a_analog_prewarped, fs)`，其中模拟原型截止频率取 `Ω_c = 2·fs·tan(π·fc/fs)`（见 §5.2 的 `reference_lowpass()`）。
