# reference_track_plan 模块说明

## 1. 系统架构

本模块是有状态的单轴参考生成器。调用方提供目标与经过时间，模块输出本拍末的参考角度、角速度和角加速度。它不读取传感器，不发送命令，也不判断机构是否已达到目标。

| 文件 | 职责 |
| --- | --- |
| [reference_track_plan.h](./reference_track_plan.h) | 配置、实例、输出类型及三个公开接口 |
| [reference_track_plan.cpp](./reference_track_plan.cpp) | 输入校验、参考计算、约束检查和成功后的状态提交 |

## 2. 数据类型

- `reference_config_t`：运动上限、跟踪增益、合法周期范围、角度环绕和饱和保护选项。初始化时复制，不持有调用方指针。
- `reference_track_plan_t`：一个实例保存一条参考轨迹的历史。不要让两个任务同时更新同一实例。
- `reference_value_t`：同一时刻的 `angle_rad`、`rate_rad_s`、`accel_rad_s2`，不是测量值。

## 3. 单拍运动模型与设计流程

一次成功的 `update` 将参考状态 $(q_0,v_0,a_0)$ 推进到 $(q_1,v_1,a_1)$。角度 $q$、角速度 $v$、角加速度 $a$ 满足 $\dot q=v$、$\dot v=a$。jerk 是加速度的变化率 $j=\dot a$。这些关系描述参考曲线，真实机构的惯量、摩擦和力矩没有进入模型。

### 3.1 从运动需求得到候选加速度

设本拍时长为 $h$，速度、加速度和正 jerk 上限分别为 $V,A,J$。`jerk_step` 用角度误差 $e$、限幅后的目标速度 $v_t$ 和目标加速度 $a_t$ 生成候选值。源码中的 `bandwidth` 记为 $w$，单位为 $\mathrm{s}^{-1}$。

$$
j_{\rm req}=w^3e+3w^2(v_t-v_0)+3w(a_t-a_0),\qquad a_{\rm req}=a_0+h j_{\rm req}.
$$

三个系数来自 $(s+w)^3$ 的展开。对于固定目标、固定带宽且未限幅的连续模型，误差满足 $e'''+3we''+3w^2e'+w^3e=0$。实际实现每拍重算 $w$，先取有效位置增益、速度增益的三分之一及 $0.25/h$ 中的最小值。当 $|e|>10^{-9}$ 时再以 $\sqrt[3]{J/|e|}$ 限制它。这一步约束位置误差项，三个误差项的总请求仍须经过下面的可行区间检查。

### 3.2 `lower` 和 `upper` 如何得到

仅有角度输入时，可显式启用 `estimate_target_rate`（零初始化默认关闭，小 yaw 启用）。
模块使用相邻成功更新的目标角最短差除以实际周期，限制到速度上限，再用带宽
`rate_servo_gain_per_s/3` 的一阶低通估计目标速度，避免位置增益较低时换向前馈过时；
提高估计带宽可能增加噪声敏感性，需结合实际目标采样率验证。
在 `rate_valid=false` 时替代速度前馈；`rate_valid=true` 时优先使用外部速度（包括真实零速度）。
`accel_valid=true` 时使用外部加速度，否则使用零，不对角度做二次差分。
两个有效标志是 update 末尾的必填参数，必须由数据源逐拍提供，不根据数值是否为零判断。
标记有效但非有限的导数拒绝整拍更新，标记无效的数值忽略。
首次更新只建立历史，reset 清空历史，
失败更新不提交历史。目标每拍应与该拍 dt 对应；低频阶梯目标或噪声输入仍需单独验证。
此模式不对角度做二次差分，不放宽原有速度、加速度或 jerk 约束，二阶兼容路径也支持。
它利用目标运动趋势降低三阶纯位置跟踪的低频滞后，但不是零延迟或未来预测，
突变时也不能消除运动约束所必需的过渡时间。有外部有效速度时，用限幅后的速度校准回退估计，
同时更新目标角历史，避免首次接入速度后短暂掉线时回退到零或未收敛状态。
下一拍缺失速度时，从校准状态继续用角度差分低通更新；无需按数据源切换配置开关。
这是有效性优先选择，不是加权融合。外部速度必须与角度同时间基、同方向且可信，
有效性不能仅代表数值有限；数据源切换本身不保证 jerk 请求连续，但输出仍受运动约束。

启用 `estimate_target_rate` 且没有外部有效速度时，模块同时估计**目标角加速度**：
对相邻两拍的目标速度（角度一阶差分）再差分一次，并用同一带宽一阶滤波，作为加速度前馈。
三阶跟踪只给速度前馈时，误差中会残留 $3w\,a_t/(s+w)^3$，在目标频段与目标同向相加，
表现为参考角幅值大于目标幅值（超调）；补上加速度前馈后该残差消失。
二阶差分对阶跃、零阶保持和噪声是脉冲而不是加速度，因此本拍差分超过加速度上限时
判为“速度上不可微”，该拍不做加速度前馈，估计值按滤波时间常数衰减到 0。
这使 100 Hz 阶梯角度输入的行为与只有速度前馈时一致，而平滑目标仍能获得加速度前馈。
外部速度有效（`rate_valid=true`）时不估计加速度，并把回退状态校准到外部速度。

离线回归入口为 `User/test/reference_track_plan_test.cpp`（独立主机程序，不加入固件源列表），
覆盖相同增益下的正弦误差改善、变周期约束、目标跳变、环绕和失败/重置历史。
Windows 仓库根目录执行 `powershell -File .\User\test\run_reference_track_plan_test.ps1`，
需要 PATH 中的主机 `g++`，直接使用项目数学头文件，不使用临时替身，也不连接硬件。
五种软件环回模式依次为：仅角度、完整导数、100 Hz 阶梯角度叠加 0.2 mrad 噪声、
持续跨越 ±pi 的匀速角、每 50/100 拍切换速度/加速度有效性；每种运行 30000 拍，
周期循环为 1.2/0.9/0.9 ms，启用饱和保护。统计丢弃前 3 秒起步过程，
检查 RMS/峰值角误差以及每拍速度、加速度、jerk 和拍内速度极值。
除模式 2（目标本身不可微）外断言最大 jerk < 500 rad/s³，锁定“参考角加速度必须平滑”这一回归。
另有高频目标用例：0.35/1.5/2.0 Hz、幅值 0.3 rad 的稳态正弦，断言参考角峰值不超过目标幅值
的 1.02/1.04/1.05 倍，用于锁定“目标频率升高时参考角幅值被放大（超调）”这一回归。
超能力用例：2 Hz → 3 Hz（0.3 s 频率平滑）且幅值 0.3 rad（需 104 rad/s² > 55），
断言参考峰值 < 0.34 rad、最大偏差 < 0.35 rad，且确实进入了位置项暂挂。
这些是规划器参考生成环回，不包含电机模型，不代表真实电机闭环效果。

`limit_step_accel` 的决策量是**拍末加速度** $a_1$。`lower` 和 `upper` 都以 rad/s² 为单位，可以同时为正，也可以同时为负。计算按以下顺序求各项约束的交集。

1. **本拍可达性。** 绝对加速度要求 $-A\le a_1\le A$，jerk 上限要求 $a_0-Jh\le a_1\le a_0+Jh$。因此初始下界为 $L=\max(-A,a_0-Jh)$，上界为 $U=\min(A,a_0+Jh)$。例如 $a_0=2$ rad/s²、$A=5$ rad/s²、$J=10$ rad/s³、$h=0.1$ s，初始区间为 $[1,3]$ rad/s²。即使请求立即反向，这一拍也无法把加速度降到零。
2. **拍末保留制动余量。** 若拍末仍有向外的加速度 $b>0$，随后用恒定反向 jerk $J_b=0.99J$ 将它降到零，速度还会增加 $b^2/(2J_b)$（加速度–时间三角形的面积）。以正向边界为例，令 $H=V(1-10^{-5})-v_0-a_0h/2$。本拍末加速度的积分贡献与后续制动合计须满足 $bh/2+b^2/(2J_b)\le H$。`braking_accel_limit` 在 $H\ge0$ 时用有理化正根收紧上界。若 $H<0$，则要求向内加速，取 $2H/h$。负向边界将速度和加速度同时反号计算，再把结果反号收紧 `lower`。
3. **拍内速度峰值。** 加速度改变符号时，速度极值可能落在采样点之间。例如 $a_0>0>a_1$ 时，过零时间为 $t_*=ha_0/(a_0-a_1)$，从拍初到峰值的速度增量为 $a_0t_*/2$。实现用原速度上限给出的余量 $V-v_0$ 检查这部分面积，必要时进一步降低上界。初始加速度为负时对称地提高下界。初始加速度向外且该侧已无余量时返回失败。
4. **选择结果。** 每个新下界用 `max` 合并，每个新上界用 `min` 合并。边界非有限或 $L>U+10^{-4}$ 时返回失败。若只是 $0<L-U\le10^{-4}$ rad/s²，取 $U$。其余情况把 $a_{\rm req}$ 截到 $[L,U]$。此容差用于区间比较，不是配置中的运动上限。

### 3.2.1 前馈反向抑制（平滑）

参考点已越过目标、而目标速度前馈又指向背离目标的一侧时，前馈不能把参考点继续推远。
实现上不能用“直接置零”：置零会把速率参考一步踩到 0，经 $3w^2(v_t-v)$ 放大成阶跃 jerk，
**每过一次目标就产生一次加速度尖峰**（实测 0.25 Hz 正弦下加速度抖动从 0.8 rad/s³ 恶化到 280 rad/s³）。
这里的抑制系数随角误差平滑变化：

$$
v_t\leftarrow v_t\cdot\frac{1}{1+(e/\varepsilon)^2},\qquad \varepsilon=10\ \mathrm{mrad}
$$

误差很小时（过零附近）几乎不抑制，保持与正常跟踪连续；误差变大（真正越过目标）时接近全抑制。
该式只在“前馈指向背离目标”时生效，不影响同向跟踪。

### 3.2.2 位置项暂挂（超能力守护）

当目标的加速度需求已超出规划能力，目标不可能被位置环跟上。此时若继续用位置误差追逐，
参考点会被加速度/速度限幅反复甩到目标两侧：实测 2 Hz→3 Hz（0.3 rad，需 104 rad/s²）
换频时参考峰值达到 0.45 rad（目标 0.30），最大偏差 0.60 rad。

`sat_hold_time_s>0` 时启用该保护。进入条件二选一：

1. **目标加速度同号超能力的持续时间** ≥ 10 ms。二阶差分取“与上一拍同号且 $|a|>A$”才累计，
   因此测角噪声（逐拍变号）、阶跃与 100 Hz 阶梯目标（单帧脉冲）都不会累计，只有真正
   需要超能力的平滑目标（如 3 Hz / 0.3 rad）会触发。这是主判据，能赶在第一次大幅摆动之前生效。
2. 位置增益已被饱和保护压到 `sat_gain_scale` 下限且本拍仍在限幅。作为无目标加速度估计
   （未启用 `estimate_target_rate` 或外部速度有效）时的兜底判据。

暂挂期间把进入位置环节的误差置 0，只保留速度/加速度前馈（速率环仍使用完整带宽
`position_gain_per_s`，且不恢复位置增益），参考点改为“与目标同速”，不再尝试缩短位置误差。
目标仍超能力时逐拍续期；目标回到能力范围后，再保持 `sat_hold_time_s` 秒即解除，
由位置项消除暂挂期间累积的偏差。

同一场景下该保护把参考峰值从 0.45 降到 0.32 rad、最大偏差从 0.60 降到 0.31 rad，
从 3 Hz 回到 0.25 Hz 后偏差收敛到 0（无残余偏移）。0.25/1/2 Hz 稳态、阶跃、斜坡、
100 Hz 阶梯叠加噪声的结果与未启用时完全一致（不触发）；3 Hz/0.1 rad 这种能力内的高频目标
也不触发（继续按正常三阶跟踪，幅值比 1.07）。4 Hz/0.1 rad 需要 63 rad/s²，已超能力，
因此转为暂挂跟随：幅值比 0.97→0.72，最大偏差 0.085→0.069（绝对误差更小）。

### 3.3 从选定加速度积分并提交

三阶分支假定一拍之内 jerk 恒定，因此加速度随时间线性变化。对加速度积分一次得到速度，再积分一次得到位置。下面的角度是环绕归一化之前的值。

$$
v_1=v_0+\tfrac12(a_0+a_1)h,\qquad q_1=q_0+v_0h+\left(\tfrac13a_0+\tfrac16a_1\right)h^2.
$$

当配置的 jerk 上限非正时，`accel_step` 走二阶兼容分支。先将“位置增益 × 角误差 + 速度前馈”截到速度范围，再将“速度增益 × 速度误差 + 加速度前馈”截到加速度范围。若积分后的速度被截断，则用 $(v_1-v_0)/h$ 回算本拍加速度。位置按平均速度 $(v_0+v_1)/2$ 积分。此分支允许相邻拍加速度跳变。

两条分支都先写局部候选状态 `next`，按配置处理角度环绕并检查三个输出是否有限。只有检查通过才更新饱和标志、增益、周期、实例状态和输出。这个提交顺序使调用方可以用返回值区分本拍结果与上次成功结果。

### 3.4 整条参考轨迹的定义与连续性

目标角给出希望到达的位置，轨迹 $q(t)$ 还规定每个时刻经过的位置。速度限制每秒能转过的角度，加速度限制速度改变的快慢，jerk 限制加速度改变的快慢。三阶分支在第 $k$ 拍使用实际时长 $h_k$。令 $\tau=t-t_k\in[0,h_k]$，实际采用的 jerk 为 $j_k=(a_{k+1}-a_k)/h_k$，则这一整拍的参考曲线为

$$
\begin{aligned}
a(t)&=a_k+j_k\tau,\\
v(t)&=v_k+a_k\tau+\tfrac12j_k\tau^2,\\
q(t)&=q_k+v_k\tau+\tfrac12a_k\tau^2+\tfrac16j_k\tau^3.
\end{aligned}
$$

连续成功更新时，上一段的末状态成为下一段的初状态。展开角度后，$q(t)$ 二阶连续，jerk 可以在拍间跳变。启用角度环绕时，输出从 $+\pi$ 附近跳到 $-\pi$ 附近是角度表示切换。跨此边界检查积分误差时应先展开角度。二阶兼容分支采用拍内恒加速度，位置和速度连续，加速度允许在拍间跳变。

### 3.5 当前实现的优化目标与验收规则

当可行区间 $[L,U]$ 非空时，选择拍末加速度等价于一维约束最小二乘问题

$$
a_{k+1}=\underset{L\le b\le U}{\arg\min}\;(b-a_{\rm req})^2
=\min\bigl(U,\max(L,a_{\rm req})\bigr).
$$

请求落在区间内时可以原样采用，落在区间外时选择最近的可行端点。由于 $h_k>0$ 且 $a_{\rm req}=a_k+h_k j_{\rm req}$，这个解也使本拍实际 jerk 与请求 jerk 的平方偏差最小。优化范围是一拍，代价函数衡量请求偏差，全程到达时间与整段 jerk 平方积分均未纳入代价函数。浮点边界轻微倒置时使用第 3.2 节的容差规则。

评估数值实现的改动时，可固定同一组初始状态、目标和周期序列，对照以下三项。先检查约束，再解释误差指标。

| 验收项 | 检查方法 |
| --- | --- |
| 运动约束 | 检查速度两端点以及拍内满足 $a(t)=0$ 的极值点。三阶分支另检查 $\lvert a_{k+1}-a_k\rvert/h_k$。分别报告各项最大越界量。 |
| 积分一致性 | 用上节多项式在 $\tau=h_k$ 求值，与输出逐项比较。位置、速度和加速度分别按各自单位报告残差。 |
| 变周期误差统计 | 对整段角度误差使用按时间加权的均方根近似 $\sqrt{\sum_k h_k e_k^2/\sum_k h_k}$，注明 $e_k$ 的采样时刻与环绕规则。单独报告拒绝更新的次数，避免沿用旧输出掩盖失败。 |

## 4. 接口与失败行为

| 操作 | 成功 | 返回 `false` 时 |
| --- | --- | --- |
| `reference_track_plan_init` | 复制配置，按给定角度静止起步 | 空指针不写入；指针有效但配置或初始角非法时，清空实例 |
| `reference_track_plan_reset` | 保留配置，重新对齐角度，将速度、加速度、计数和最近周期清零，恢复正常增益 | 空指针、未初始化或非有限角度不修改实例 |
| `reference_track_plan_update` | 提交本拍状态，并写入独立输出缓冲区 | 状态与输出不变。此时缓冲区中的值不是本拍结果 |

## 5. 初始化流程

先准备完整配置与有限的初始角，再检查 `init` 返回值。`reset` 假定从静止开始，不能用来无扰接管正在运动的轴。运行期间修改原始配置不会自动同步到实例。

云台调用方在收到小 yaw 首帧反馈前不推进规划器，也不更新时间基。
电机默认角度 0 减去机械零点得到的偏置不代表有效姿态，不能用它 reset。
首次有效调用将规划器对齐到反馈角，并将速度/加速度前馈滤波器清零；不覆盖上游目标角。
初始化从默认零值切换到有效反馈角仍会改变监视值，这不是一次受运动约束的 update。
验证轨迹连续性应从初始化完成后开始，同时记录反馈时间戳与规划时间戳。

### 5.1 如何确定配置值

结构体声明定义字段，不提供默认值。先确定角度的含义和调用周期，再填写参考曲线允许的运动范围。以下规则描述规划器自身的输入，不替代机构的独立保护，也不提供通用实机整定值。

| 字段 | 取值依据与修改影响 |
| --- | --- |
| `wrap_angle` | 同一方向相差整圈仍表示同一目标时可取 `true`；若圈数有意义，取 `false` 并输入连续角。例如后者能区分 0 与 $2\pi$。两种模式都不检查机械限位。 |
| `dt_min_s`、`dt_max_s` | 依据调用方时间戳的分辨率、正常调度间隔和允许的最长中断确定，单位为秒，要求 $0<dt_{min}\le dt_{max}$。两个端点均接受。超出范围是调用失败，不应靠截断实际周期或不断放宽范围消除报错。 |
| `max_rate_rad_s`、`max_accel_rad_s2` | 分别填入规格已批准的参考角速度、角加速度上限，均为有限正数。二者限制的是不同量；不能从最高速度单独推出允许的加速度。若上游规格用度，换成弧度时乘 $\pi/180$，时间单位保持为秒。 |
| `max_jerk_rad_s3` | 要求相邻拍加速度的变化率受限时，填入规格允许的正上限（rad/s³）；有限非正值选择二阶兼容路径。填零不是“加速度不能变化”。 |
| `position_gain_per_s`、`rate_servo_gain_per_s` | 均为有限正数，单位为 1/s，是参考模型的增益而非电机 PID 参数。二阶模式下，前者将角误差换算为速度需求，后者将速度误差换算为加速度需求。三阶模式下二者共同限制带宽（见 3.1）；仅改变非主导项可能不改变输出。不能从运动上限唯一推算这两个值。 |
| `accel_sat_guard_enable` | 依据是否要求持续限幅时自动降低位置增益选择。关闭时仍执行运动约束，成功更新后增益比例为 1、连续限幅计数为 0。 |
| `sat_gain_scale` | 保护启用时取 $(0,1]$，表示允许降到的最低增益比例，不是首次限幅时立即切换到的比例。`1` 合法，表示不降增益。 |
| `sat_release_per_s` | 保护启用时取有限非负数（1/s）。每次成功更新最多改变此值乘以实际周期的比例，降低和恢复共用同一速率。`0` 表示保持当前比例。 |
| `sat_hold_time_s` | 保护启用时取有限非负数（s）。位置项暂挂的保持时长；`0` 关闭超能力守护（`accel_sat_guard_enable` 关闭时忽略）。整定为大于一个目标周期的 1~2 倍，云台取 0.3 s。 |

### 5.2 如何修改并确认生效

1. 在调用方准备一份完整的候选 `reference_config_t`，按字段名赋值，注明单位和取值来源。修改头文件注释、原配置变量或调用 `reset` 都不会替换已初始化实例中的配置。
2. 在独立实例上调用 `init` 并检查返回值，不要用正在工作的实例试探候选值：配置无效时 `init` 可能清空该实例。新实例从静止起步，不适合在运动中直接接管。
3. 使用相同初始状态、目标序列和时间戳离线比较配置，按 3.5 节记录约束、积分残差及失败次数。仅在已静止且角度已对齐时采用新配置；本模块没有保持运动状态的热更新接口。

## 6. 调用周期与收发

无收发、注册或节流。每次 `update` 传入从上次有效推进到本次的真实时间（秒）；超出配置的闭区间即拒绝。长时间中断后应由调用方决定是否重新对齐，不应伪造正常周期。

## 7. 输入、单位与坐标

输入和输出使用 rad、rad/s、rad/s²，jerk 上限单位为 rad/s³。调用方负责统一零点和正方向。`wrap_angle` 启用时，目标误差取最短角，恰好相差半圈取正向；关闭时按连续角相减。非有限目标角或周期使更新失败；非有限的速度、加速度前馈各自按零处理。

## 8. 输出约束

配置中的速度、加速度上限和两个跟踪增益必须有限且为正。正的 jerk 上限启用三阶路径，有限的非正值选择二阶兼容路径，不保证 jerk 连续。饱和保护启用时，增益下限须在 `(0, 1]` 内，恢复速率须有限且非负。数值约束仅作用于生成的参考，不能替代机械位置或执行器保护。

## 9. 离线与故障检测

模块无法检测目标是否过期或传感器是否掉线。调用方应分别检查数据新鲜度和每次调用的返回值。`dt_used_s` 记录最近成功使用的周期，不是心跳时间戳。

## 10. 使用示例

以下函数接收调用方已填好的配置，只演示初始化及一次离线更新。连续运行时保留 `plan`，不要每拍重新初始化。

```cpp
#include "reference_track_plan.h"

bool example_step(const reference_config_t &config, float start_rad, float goal_rad,
                  float elapsed_s, reference_value_t &sample)
{
    reference_track_plan_t plan = {};
    if (!reference_track_plan_init(&plan, &config, start_rad)) return false;
    return reference_track_plan_update(&plan, goal_rad, 0.0f, 0.0f, elapsed_s, &sample, false, false);
}
```

### 连续调用时如何对照源码

初始化一次并保留 `plan`。每拍传入目标角、可用的前馈和实际经过的秒数，只有 `update` 返回 `true` 才读取 `sample`。需要从新的静止角重新开始时调用 `reset`。

| 按执行顺序阅读 | 这一段处理什么 |
| --- | --- |
| `reference_track_plan_init` / `reset` | 初始化先复制配置，再复用重置逻辑。重置保留配置，从指定角度、零速度和零加速度重新开始。 |
| `reference_config_valid` / `reference_state_valid` | 更新前分别检查配置和上一拍的参考值。例如，若速度上限已降到当前参考速度以下，更新会失败。 |
| `angle_error` | 用目标角减去上一拍参考角。启用环绕时取最短角，恰好半圈统一取正向。 |
| 前馈反向抑制、超能力检测与暂挂判定 | 估算目标速度/加速度（必要时），对指向背离目标的前馈做平滑衰减（§3.2.1），并由“同号超能力持续时间”与饱和历史决定本拍是否暂挂位置项（§3.2.2）。 |
| `jerk_step` → `limit_step_accel` → `braking_accel_limit` | jerk 上限为正时，先由跟踪误差计算所需拍末加速度，再用加速度、jerk 和速度约束收窄可行区间。选定拍末加速度后，按本拍 jerk 恒定积分得到速度和角度。 |
| `accel_step` | jerk 上限为零或负数时走此分支。先由角度误差求期望速度，再由速度误差求加速度。若积分后的速度被限幅，用实际速度变化量回算加速度。 |
| `update_saturation` 与结果提交 | 本拍结果通过有限性检查后才更新历史和输出。保护开启时, 连续受限会降低下一拍使用的增益并累计帧数, 解除限制后逐拍恢复增益并清零计数; 同时维护连续受限时间与“目标加速度同号超能力持续时间”, 由此决定下一拍的位置项是否暂挂(§3.2.2)。 |

## 11. 常见错误与排查

| 现象 | 优先检查 |
| --- | --- |
| 初始化失败 | 配置是否全零、周期上下限是否颠倒、初始角是否有限 |
| 更新失败且输出没有变化 | 是否误传毫秒、输出是否指向 `plan.value`、修改约束后历史状态是否仍可达 |
| 参考角幅值大于目标幅值（冲过目标） | 目标频率是否已接近加速度上限 $A/(2\pi)^2/\text{幅值}$；`estimate_target_rate` 是否启用（加速度前馈依赖它）；有外部速度时该估计不生效 |
| 规划角加速度有明显毛刺/波动 | 是否又把前馈硬置零（应用 §3.2.1 的平滑抑制）；是否又在参考环里做了硬限幅/重置加速度这类不连续操作；目标本身是否不可微（阶梯/噪声） |
| 换频/阶跃后参考点大幅来回穿越目标 | 目标所需加速度是否超过 `max_accel_rad_s2`；此时应启用 `sat_hold_time_s>0` 让位置项暂挂，而不是靠位置环硬追 |
| 跨半圈时方向与预期不同 | 是否需要连续角而非最短角，以及应用层是否另有机械限位 |
| `sat_frames` 始终为零 | 计数仅在饱和保护启用时累积；它不是全部失败帧的计数器 |
