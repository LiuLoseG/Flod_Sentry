# 轮系运动学解算模块 · 总体规划与设计说明

> 本文只做**规划与描述**：定位范围、模块边界、参考坐标系规定、轮系定义、执行流程编排、里程计取舍、接口设计原则、移植与联调口径。
>
> 本文**不含**接口签名、类成员与代码。接口以 `wheel_system_solution.h` 为唯一权威；各轮系的推导、参数、API、示例、标定见分册：[全向轮](./omni_wheel.md) · [麦轮](./mecanum_wheel.md) · [舵轮](./steer_wheel.md)。

## 1. 定位与范围

### 1.1 设计目标

| # | 目标 | 手段 |
|---|------|------|
| G1 | 一套代码覆盖三种轮系 | 三个独立 class，同名同义范式，互不继承 |
| G2 | 与硬件彻底解耦 | 只吃/吐结构体，不持有 CAN、电机、IMU 句柄 |
| G3 | 固件与 PC 同源 | 无堆分配、无 OS 依赖、无可变全局状态 |
| G4 | 坏数据不扩散 | 入口校验（运动学反馈逐通道跳过、里程计快照整帧提交）+ 解算整帧校验 + 输出保持 |
| G5 | 里程计可交叉验证 | 编码器里程计与速度里程计各自独立维护位姿 |

### 1.2 范围

| 范围内 | 范围外（归属） |
|--------|----------------|
| 逆解：底盘速度 → 执行器目标 | 报文收发 / 字节序 / 掉线检测（驱动层、BSP） |
| 正解：执行器反馈 → 底盘速度 | 电机速度环、位置环 PID（驱动层） |
| 里程计：位移差分 + 速度积分 | 底盘行为状态机（上层 chassis，本模块只接收模式号） |
| 舵轮优化：就近转位 / 斜坡 / 余弦 / 死区 / 限速 | 路径规划、定位融合（决策 / 导航层） |
| 参数校验与数值健壮性 | 云台、发射、悬挂（其它模块）；打滑与地形建模（不建模） |

### 1.3 非目标

- **不追求"一套公式通吃"**：三种轮系几何差异太大，强行抽象只会让符号更难核对。
- **不提供在线标定**：几何量运行中改变会破坏逆解 / 正解 / 里程计三者的一致性。
- **不内置里程计融合**：融合会掩盖打滑诊断信息，两套位姿都交给上层。

## 2. 模块边界

```
上层（chassis / 状态机 / 导航）── 给：期望速度 + 模式号
                              ── 取：执行器目标、实测速度、两套位姿
        │ 纯结构体，无句柄
本模块：逆解 · 正解 · 编码器里程计 · 速度里程计 · 舵轮优化   ← 纯算法，可 PC 单测
        │ 物理量（m、m/s、rad、rad/s）
驱动层：电机（速度环 / 位置环、反馈解析）、IMU
```

四条边界规则：

1. **不做单位换算**：报文 → 物理量在驱动层完成。
2. **不做电机方向纠正**：方向反改驱动层符号，不改公式（§3.8）。
3. **不做限幅兜底**（舵轮除外）：全向轮 / 麦轮输出由上层限幅。
4. **不做线程保护**：约定单写者，一个实例只在一个上下文内调用。

## 3. 参考坐标系规定

> 本节是**全模块唯一的坐标系定义来源**，分册公式一律以此为前提。

### 3.1 建模前提

1. **二自由度平面刚体**：状态量仅 `x / y / yaw`，不建模 `z`、`roll`、`pitch`。
2. **四轮着地、纯滚动**：无纵向滑移。全向轮 / 麦轮靠辊子获得横向自由度，舵轮靠主动转向消除横向约束；滑移不建模，只体现为里程计误差。
3. **瞬时几何关系**：单周期内轮径、力臂、轮心投影、方位角视为常量，几何量变更必须重新初始化。

### 3.2 坐标系清单

| 符号 | 名称 | 原点 | X 轴 | 承担的量 |
|------|------|------|------|----------|
| `F_b` | 机体系 | 底盘旋转中心 | 车头正前（Y 向车身左侧） | 逆解输入、正解输出 |
| `F_w` | 世界系 | 上电时刻底盘中心 | 上电时刻车头方向 | 两套里程计位姿 |
| `F_i` | 轮位系（i=0..3） | 第 i 个**轮心** | 该轮**有效驱动方向**（仅一维） | 单轮速度投影 |

三者均为右手系、Z 向上。`F_b` 与 `F_w` 原点语义相同、朝向差 `yaw`。位姿描述**底盘中心**，其它参考点需上层自行平移。

### 3.3 机体坐标系与正方向

```
            +X_b (车头 / 前)
                 ↑
   +Y_b (左) ←───┼───→ −Y_b (右)
```

| 量 | 正方向 | 零点 | 取值 |
|----|--------|------|------|
| `vx` / `vy` | `+X_b` 前 / `+Y_b` 左 | — | m/s |
| `vw` | 绕 `+Z_b` **逆时针（CCW）** | — | rad/s，`> 0` 为左转 |
| `yaw` | 绕 `+Z_b` 逆时针 | `+X_b` | `[-π, π)` |

### 3.4 轮位编号与有效驱动方向

自车顶俯视**逆时针 1→2→3→4**，下标固定 `[0]=FL [1]=RL [2]=RR [3]=FR`：

```
                     +X (车头)
                          ↑
        FL [0]            │            FR [3]
       (+x, +y)           │           (+x, −y)
               ╲          │          ╱
   +Y (左) ←──────────────┼──────────────→ −Y (右)
               ╱          │          ╲
        RL [1]            │            RR [2]
       (−x, +y)           │           (−x, −y)
```

方位角（`+X_b` 为 0、CCW 正）：45° / 135° / 225° / 315°，轮心坐标 `d·(cos φ, sin φ)`，即 `(±d/√2, ±d/√2)`。

三种轮系共用编号与方位角，差异只在"有效驱动方向"：

| 轮系 | 有效驱动方向 | 随时间变化 |
|------|--------------|------------|
| 全向轮 | 轮心圆周的**切向** | 否 |
| 麦轮 | 由 45° 辊子决定的**对角方向**（内/外八决定符号表） | 否 |
| 舵轮 | 由**实测舵向角**决定 | **是** |

下标 → 物理轮位 → 电机 ID 的映射由上层 chassis 负责，本模块不做硬件顺序假设。

### 3.5 世界坐标系与位姿语义

| 项 | 约定 |
|----|------|
| 位置原点 / 航向零点 | 上电时刻底盘中心 `(0,0)`；上电时刻车头 = `+X_w`（`yaw = 0`） |
| `yaw` 区间 | `[-π, π)`，位姿清零后回到 `0` |

`F_w` 是惯性系。机体运动完全由 `yaw` 承担，故 `yaw` 出错时位置误差表现为**绕圈**而非平移——这是区分航向误差与位移误差的关键判据。

### 3.6 变换原则

**(a) 轮心速度**（三种轮系逆解的统一起点）：`v_c,i = v_body + ω × r_i`，即

```
v_c,i,x = vx − vw·d_i·sin φ_i        v_c,i,y = vy + vw·d_i·cos φ_i
```

**(b) 机体位移 → 世界位移**：`dx_w = dx·cos ψ − dy·sin ψ`，`dy_w = dx·sin ψ + dy·cos ψ`（反变换用 `−ψ`；角度本身无偏置）。

**(c) 积分顺序**：先更新 `yaw`，再用**更新后**的 `yaw` 变换位移（一阶显式欧拉）。单周期旋转量大时应改中值法，属已知精度边界。

**(d) 自检口径**（改任何符号后必过）

| 检查项 | 期望 |
|--------|------|
| `vx > 0`，`yaw = 0` | `x` 增、`y` 不变 |
| `vx > 0`，`yaw = π/2` | `x` 不变、`y` 增 |
| `vw > 0` | `yaw` 递增，过 `π` 折回 `−π` |
| 逆解结果喂回正解（全向轮 / 麦轮） | 还原原 `(vx, vy, vw)` |

### 3.7 角度体系

| 角度 | 零点 | 区间 | 多圈 |
|------|------|------|------|
| `yaw` | `+X_w` | `[-π, π)` | 否 |
| 轮位方位角 | `+X_b` | 常量 | 否 |
| 舵向**几何**角 | `+X_b` | `[-π, π)` | 否 |
| 舵向**编码器**角 | 电机零位 | 累计 | **是** |
| 舵向零位偏置 | `+X_b` ↔ 电机零位 | 常量 | 否 |
| 舵向误差 | — | `[-π, π)` | 否 |
| 轮向累计转角 | 电机零位 | 累计 | **是** |

1. **几何角与编码器角差一个零位偏置**（`编码器角 = 几何角 + 零位`）：逆解下发时**加**，正解 / 里程计还原时**减**。零位全 0 时数值相同，但代码路径不同，不得省略。
2. **多圈量只有两处**（舵向编码器角、轮向编码器角）：参与三角运算或差分前必须折到 `[-π, π)`；下发位置环的量**绝不**折返。

归一化统一折到 `[-π, π)`（非 `[0, 2π)`），上层角度闭环不得假设单调递增。

### 3.8 符号红线

| # | 约定 | 反了的表现 |
|---|------|------------|
| 1 | `vw > 0` = 左转（CCW 正） | 原地旋转反向，平移正常 |
| 2 | 轮位逆时针编号 `FL→RL→RR→FR` | 特定方向斜走，旋转时四轮速度异常 |
| 3 | 全向轮电机正方向与切向相反 | 整车 `vx/vy` 全反 |
| 4 | 麦轮电机正方向与驱动方向相同 | 整车 `vx/vy` 全反 |
| 5 | 舵向角以 `+X` 为 0、CCW 正 | 四轮指向呈"风车"或交叉 |
| 6 | 舵轮下发的轮速已含方向符号 | 下游再取绝对值 → 反向跑 |
| 7 | 舵轮下发的舵向目标已含零位、是多圈量 | 下游再折返 → 在 ±π 处来回翻转 |
| 8 | IMU 航向为 `+X` 为 0、CCW 正 | 航向镜像，位置绕错方向 |

改符号的唯一正确做法：整车全反 → 改**上层电机符号**；单轮反 → 改**那一路电机**；绝不单独改逆解或单独改正解 / 里程计（三者符号配套，§3.6(d) 即为此设）。

> **本车现状（舵向角符号）**：舵向编码器正向与几何 CCW 相反，`Wheel_Azimuth[i]` 在舵向角度坐标系里表现为镜像，因此**旋转耦合项取 `d·(+sinφᵢ, +cosφᵢ)`**：逆解 `vel_x = vx + vw·d·sinφ`、`vel_y = vy + vw·d·cosφ`，正解与编码器里程计配套写 `u·sin(θ+φ)/d`。
> 这三处（逆解 / 正解 / 里程计）是**同一约定的三面**，任何一处单独取反，纯自旋时实测 `vw` 与 `dyaw` 都会变成 `0` 或反号。实测校核见 [steer_wheel.md §3.2](./steer_wheel.md)。
> 上层保持 `+vw` 为左转（CCW 正），不要在 [`chassis_overall_mobile_control()`](../APP/chassis/chassis.cpp) 再对 `map_robot_speed.vw` 取反。

### 3.9 单位

| 量 | 单位 | 备注 |
|----|------|------|
| `vx / vy`、`x / y` | m/s、m | 机体系速度、世界系位置 |
| `vw`、`yaw`、几何角 | rad/s、rad | CCW 正 |
| 轮速类量 | rad/s | **电机输出轴**角速度，轮线速度 = 角速度 × 轮半径 |
| 编码器角类量 | rad | 多圈累计 |
| 力臂 / 轮心投影 | m | **中心到轮心**，不是半轴距 |
| 控制周期 | s | 仅速度里程计积分与舵向斜坡等效速率使用 |

## 4. 轮系定义与选型

### 4.1 统一视角与三系对照

三者都可写成 `执行器速度 = 驱动矩阵 × 底盘速度`，差异只在矩阵性质：全向轮与麦轮是常量矩阵、三列两两正交，正解等价于加权平均，一帧算完无需解方程；舵轮的矩阵随舵向角变化，必须先定角再定速，因而存在过渡过程。矩阵与推导见分册。

| 维度 | 全向轮 | 麦轮 | 舵轮 |
|------|--------|------|------|
| 构型 | 4×45° 全向轮，切向驱动，轮心在半径 `d` 圆上 | 4×麦轮，辊子 45°，**外八**布局 | 4×（舵向 + 轮向），方位角 45°/135°/225°/315° |
| 自由度 | 3 → 4 轮，1 冗余 | 3 → 4 轮，1 冗余 | 8 执行器 → 3，冗余多但只需一组自洽解 |
| 驱动矩阵 | 常量（切向固定） | 常量（辊子 45° 固定） | **随舵向角变化** |
| 逆解代价 | 一行乘加 | 一行乘加 | 开方 + 反正切 + 优化流水线 |
| 关键约束 | 只能感知切向分量 | 等效驱动方向为对角，横向以 ±1 权重进入 | **不可解耦**：舵向角决定轮速有效性 |
| 需要反馈 | 轮速、轮向多圈角、（可选）IMU | 同左 | 舵向多圈角、轮速、轮向多圈角、（可选）IMU |
| 关键参数 | 轮半径、力臂 `d` | 轮半径、轮心 X/Y 投影（其和决定旋转项） | 轮半径、逐轮力臂、方位角表、零位、斜坡步长、轮速上限、静止阈值、舵向死区、三开关 |
| 输出 | 4 路轮速 | 4 路轮速 | 舵向多圈目标 + 轮向目标（含符号），另有纯几何解供诊断 |
| 内置限幅 / 过渡过程 | 无 / 无 | 无 / 无 | 斜坡 + 余弦削减 + 全局限速 / 有（舵向对齐期） |
| 里程计精度潜力 | 高 | 中（打滑） | 高（依赖实测舵向角） |
| 承载 / 越障 · 机械复杂度 | 低 · 中 | 中 · 低 | 高 · 高 |
| 调试难点 | 符号矩阵 | 辊子朝向 | 优化流水线联动 |

### 4.2 各系要点

- **全向轮**：最"干净"，逆解为纯线性组合、无优化环节；代价是辊子外露，对越障与侧向冲击敏感，且每帧输出只对当帧有效。
- **麦轮**：轮子不外露、耐脏耐冲击；代价是辊子摩擦损耗，横移与原地旋转的打滑更明显，故里程计弱于全向轮。**辊子朝向是机械硬约束**——内/外八装反表现为"前进正常、横移变斜移"，不能靠改单轮符号硬凑。
- **舵轮**：承载与扭矩最高、里程计最准；代价是机械复杂，且必须处理优化流水线（§5.4）的三条联动规则。

## 5. 执行流程

### 5.1 生命周期

```
初始化（一次）：写参数 + 清零状态 + 置首帧标志
   →  等周期循环（每 T）：采反馈 → 正解 → 里程计 → 目标 → 逆解 → 下发
```

- 初始化只做两件事：写入可配参数、清零并把首帧标志置位。**轮径、方位角、编码器零位是编译期量**，不在初始化里设置；力臂是可运行时调整的量（`init()` 形参非法时回退到编译期默认值）。
- 循环内每类动作**每周期恰好一次**，不重入、不合并、不跳帧（例外见 §5.3）。
- 初始化后前若干帧处于**基准建立期**：编码器里程计首帧只记录基准不产生位移；IMU 路线首帧直接对齐绝对航向。

### 5.2 单周期编排

| 阶段 | 职责 | 失败策略 |
|------|------|----------|
| ① 采集反馈 | 驱动层缓存 → 模块内部快照（轮速、轮向多圈角、舵向多圈角、IMU 航向） | 轮速 / 舵向反馈逐通道跳过；里程计用的轮向角、舵向角**整帧有效才提交**（半新半旧会算出虚假位移），坏通道恢复后位移一次补齐 |
| ② 正运动学 | 反馈 → 底盘实测速度 | 关键量非法 → 整帧跳过，输出保持 |
| ③ 速度里程计 | 实测速度按周期积分 | 周期非法或落死区 → 不积分 |
| ④ 位移里程计 | 轮位移差分 → 机体系位移 → 世界系 | 首帧只建基准；坏通道整帧不提交且不推进差分基准；死区内的位移**只累积不丢弃**，达阈值后补积分 |
| ⑤ 目标写入 | 上层期望速度（+ 舵轮模式号） | 速度非法不写；舵轮模式号**无条件写入** |
| ⑥ 逆运动学 | 目标 → 执行器目标（舵轮还读当前反馈与上周期舵向目标） | 输入端非法 → 整帧跳过 |
| ⑦ 下发 | 取输出给速度环 / 位置环 | 越界下标返回 0 |

编排三判据：**"写"在"读"之后**（覆盖共享字段的解算排在读它之后）、**"积分"在"求值"之后**、**"反馈"在全流程之前**（不允许半新半旧）。

数据流：

```
轮速/舵向反馈 ─┬─► 正解 ─► 底盘实测速度 ─► 速度里程计 ─► 速度位姿
               └─► （舵轮：就近转位 / 死区 / 误差 的输入）
编码器角 ────────► 位移里程计（+ IMU 航向） ─► 编码器位姿

上层指令 ─► 目标 ─► 逆解 ─► 执行器目标 ─► 下层 PID
                     ▲ 当前舵向反馈、上周期舵向目标（舵轮）
```

### 5.3 顺序约束与违例后果

| # | 约束 | 违反后现象 |
|---|------|------------|
| 1 | 反馈采集在逆解之前 | 无舵向轮系的轮速字段同时承载反馈与指令，下发值变反馈值 |
| 2 | 正解在逆解之前（无舵向轮系） | 实测速度 ≡ 目标速度，速度里程计虚高 |
| 3 | 速度里程计在正解之后 | 位姿滞后一帧或冻结 |
| 4 | 编码器采集在位移里程计之前 | 里程计用陈旧数据 |
| 5 | 每个里程计每周期恰好一次 | 调两次位移翻倍；漏调丢步 |
| 6 | 目标写入与逆解同周期 | 逆解用上一周期目标（滞后一拍，需知情） |
| 7 | 舵轮逆解每周期调用 | 斜坡基准不更新，舵向目标停滞（"走一下停一下"） |
| 8 | 位姿清零后不立即采信 | 下一帧才重建基准，第一帧为原点 |

### 5.4 舵轮优化流水线

九环节，可单独关闭或调阈值：

| 序 | 环节 | 解决的问题 | 可关闭 |
|----|------|------------|--------|
| ① | 逐轮几何逆解 | 得到几何上该指向哪、转多快 | 否 |
| ② | 静止判定 | 零指令时舵向乱摆、轮子小幅爬行 | 阈值可调 |
| ③ | 就近转位 | 每次多转 180° 浪费时间（含 ±90° 翻转迟滞，防边界抖动） | 是 |
| ④ | 斜坡限幅 | 阶跃目标导致电流尖峰与合力突变 | 是 |
| ⑤ | 舵向死区 | 小误差时的持续微调抖动 | 阈值可调 |
| ⑥ | 余弦削减 | 未对齐时"边转边冲"的方向偏差 | 是 |
| ⑦ | 方向合成 | 把方向符号并入轮速目标 | 否 |
| ⑧ | 静止清零 | 保证零指令时轮速彻底为 0 | 否 |
| ⑨ | 全局限速 | 多轮合成后单轮超限 | 阈值可调 |

三条**不可解耦的联动**（设计取舍，非缺陷）：

1. **死区依附余弦开关**：关闭余弦削减会连带失去防抖；既要满轮速又要防抖时，应保留余弦开关并调小死区。
2. **方向符号必须原样传递**：符号已并入轮速目标，下游取绝对值会导致反向运动。
3. **斜坡以上一周期输出为基准**：故逆解必须逐帧调用，不可跳帧或按需调用。

### 5.5 限幅与保护

| 保护 | 全向轮 / 麦轮 | 舵轮 |
|------|----------------|------|
| 单轮速度上限 | 外部负责 | 内置，四轮**等比缩放** |
| 舵向变化率 · 未对齐削减 · 零指令静止 | — | 内置 |
| 坏数据隔离 | 内置 | 内置 |

用等比缩放而非逐轮截断：逐轮截断会改变运动形态（如原地旋转被截成"边走边转"），等比缩放只降速、保持方向与形态。

## 6. 里程计设计

### 6.1 为什么保留两套

| | 编码器里程计 | 速度里程计 |
|---|---|---|
| 物理含义 | 轮子**实际滚了多远** | 按**实测底盘速度**推算走了多远 |
| 强项 | 短时、低速、无打滑时最接近真实 | 对打滑不敏感，低速稳定 |
| 弱项 | 打滑；慢速时位姿滞后约 1 个死区量（位移在累积器里等触发） | 误差随时间累积；舵轮过渡期不可信 |
| 典型用途 | 定位主来源 | 交叉校验打滑、速度前馈 |

两者各自维护一份位姿、互不覆盖，相减即打滑程度的量化指标——这正是保留双套而非"一套加融合"的原因。

### 6.2 航向路线与死区

编码器里程计有两条航向路线，**只应启用其一**（混用会让航向在两种来源间跳变）：

| 路线 | 航向来源 | 适用 |
|------|----------|------|
| 自持积分 | 由轮位移反解出的航向增量累积 | 无 IMU 或 IMU 不可信 |
| IMU 参考 | 直接用外部航向，位移仍由轮子算 | 有可靠 IMU，抗打滑 |

IMU 路线要求外部航向与本模块约定一致（`+X` 为 0、CCW 正），否则由上层先转换。

| | 编码器里程计 | 速度里程计 |
|---|---|---|
| 死区判据 | **累积位移**（抖动正负互抵，达死区才触发） | **瞬时速度** |
| 与调用频率 | **无关**：单帧位移小则多攒几拍，累计量不变 | **无关**：速度阈值不随周期变化 |
| 表现 | 慢速时位姿最多滞后 1 个死区量（线 0.1 mm / 角 0.001 rad），**不丢位移** | 死区偏大时吞掉真实小速度 |

编码器里程计采用"累积-触发"：不足死区的帧把位移留在 `odom_residual_*` 里，累积到死区后连同历史位移一次积分。这样既不会被单帧噪声推动（`+n / −n` 抖动互抵），也不会像逐帧死区那样把慢速运动整帧丢掉——后者在 1 kHz 下等价于"低于 0.1 m/s、1 rad/s 完全不输出"。

由此得到两条使用约定：

1. **位置里程计与角度里程计共用同一套累积器**，同一实例只应启用一条航向路线（见上表），否则累积器会被两路口径的数据交替填充。
2. **`reset_position()` 会清空累积器**，避免清零前的未积分位移在清零后突然补上；`set_position()` 只改数值、不动累积器（保持位移连续性）。

### 6.3 首帧与复位语义

| 操作 | 语义 |
|------|------|
| 上电 / 初始化 | 首帧只建基准，不产生位移 |
| 位姿清零 | 归零**并**要求下一帧重建基准（避免清零瞬间跳变） |
| 位姿重定位 | 只改位姿数值，**不**重建基准（位移连续性保持） |

把"重定位"当成"清零"，会导致下一帧出现一次虚假位移。

## 7. 接口设计原则

**范式**（三个 class 一致）：写入输入（结构体）→ 无参解算 → 读取输出（标量 getter）。

| 取舍 | 选择 | 理由 |
|------|------|------|
| 回调带参数 | **否** | 避免参数与内部状态不一致；输入集中一处写入便于校验 |
| 返回错误码 | **否** | 实时路径无法逐帧处理错误，改为"输出保持" |
| 输入传递 | 结构体整体 | 一次拷贝一次校验，避免逐参数拼装遗漏 |
| 输出访问 | 标量 getter | 不暴露内部数组，越界由 getter 兜底 |

**六条防御原则**

1. 运动学入口逐通道校验：轮速、舵向反馈坏通道跳过，不牺牲同帧其它有效数据。
2. 里程计入口整帧提交：轮向角、舵向角必须同帧全部有效才写入快照。只替换坏通道等于用旧值冒充"该轮没动"，四轮合成后会算出虚假平移；整帧丢弃且**不推进差分基准**，坏通道恢复后位移一次补齐，累计位移一条不丢。
3. 解算入口整帧校验：关键输入非法则整帧放弃，输出保持上一帧。
4. 参数静默拒绝：非法（非有限、除数为 0、破坏几何一致性）不写入、不报错；纯开关类无条件写入。
5. 初始化回退默认：形参非法时回退编译期默认值，不留半初始化状态。
6. 角度定期折返：可能无限增长的角度折回单圈，避免浮点精度退化。

**并发模型**：单写者。一个实例只在一个上下文（一个 task 或一个 ISR）内被完整调用，内部无锁、无临界区。跨上下文读输出须自行加快照或临界区；把解算拆到两个上下文会直接违反 §5.3。

## 8. 移植与联调

### 8.1 换车清单

按序核对，任一项错位都表现为"方向反"或"里程计漂"：

| 序 | 项目 | 要点 |
|----|------|------|
| 1 | 轮半径 | 实测直径 / 2；比例误差直接映射为里程误差 |
| 2 | 力臂 / 轮心投影 | **中心到轮心**，不是半轴距、不是半轮距 |
| 3 | 舵轮方位角 | 角度表与三角表必须同步重算 |
| 4 | 编码器零位 | 舵向电机读数为 0 时轮子实际指向与 `+X` 的偏差；改 `Enc_Zero_Angle[4]` 常量后重新编译 |
| 5 | 电机正方向 | 单轮反改那一路；整车全反改上层符号 |
| 6 | 控制周期 | 必须与实际调用间隔一致 |
| 7 | 优化参数 | 斜坡、死区、静止阈值、限速上限（见舵轮分册） |
| 8 | 轮位映射 | 下标 → 物理轮位 → 电机 ID 三方一致 |

**符号红线**：无舵向轮系的逆解、正解、里程计三处符号相互校验（逆解结果喂回正解应还原原速度），只改一处会让"正逆解互逆"与"里程计方向"同时失效。

### 8.2 联调检查表

| 现象 | 优先排查 |
|------|----------|
| 前进正常、转向反 | `vw` CCW 正约定 |
| 整车 `vx/vy` 全反 | 电机符号约定（全向轮与麦轮安装正方向相反） |
| 正解速度 ≡ 目标速度 | 先逆解后正解（§5.3 约束 2） |
| 里程计直线漂移 | 轮半径未标定（跑 1 m 直行做比例校验） |
| 里程计转向漂移 | 力臂用了半轴距而非中心到轮心距离 |
| 里程计方向与实际相反 | 电机符号；无舵向轮系注意实现中的整体取负 |
| 慢速时位姿略微滞后（毫米级） | 编码器里程计累积-触发死区的正常表现（§6.2），长时间静止后停止输出 |
| 位姿完全不动、速度里程计正常 | 编码器里程计被跳帧或未调用（§5.3 约束 5） |
| 位姿逐周期翻倍 / 停滞 | 里程计每周期调用次数 ≠ 1（§5.3 约束 5） |
| 位姿清零后跳变一次 | 混淆"清零（重建基准）"与"重定位（不重建基准）"（§6.3） |
| 舵轮原地抖动 | 舵向死区或静止阈值过小 |
| 舵轮随速度方向乱摆 | 就近转位关闭且误差 > 90°，余弦项把轮速压到 0 |
| 大角度换向"卡住不走" | 同上，属"先摆轮后走"的既定行为 |
| 舵向下发后在 ±π 处翻转 | 下游对多圈目标又做了一次折返（§3.8 第 7 条） |

调试观测项：底盘实测速度、四轮单帧位移、机体系单帧位移、两套位姿——足以定位绝大多数方向 / 尺度 / 顺序类问题。
